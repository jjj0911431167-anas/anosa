PROJECT: منصة تواصل اجتماعي متكاملة (نظام مراسلة ومكالمات شامل)

الهدف:
إنشاء تطبيق/موقع تواصل اجتماعي متكامل يجمع بين واتساب + تيليجرام مع ميزات إضافية قوية، ويعمل كتطبيق حديث وسريع.

------------------------------------------------------------

1. نظام الدردشة
- محادثات خاصة بين المستخدمين
- مجموعات كبيرة العدد
- قنوات بث مثل تيليجرام
- رسائل فورية (Real-time)
- أنواع الرسائل:
  - نصوص
  - صور
  - فيديوهات
  - ملفات (PDF, ZIP, APK وأي نوع ملف)
  - رسائل صوتية
- مميزات الرسائل:
  - الرد على رسالة
  - إعادة توجيه
  - حذف للطرفين
  - تعديل الرسائل
  - إشعار تم الاستلام وتمت المشاهدة
  - رسائل تختفي بعد وقت أو بعد المشاهدة

------------------------------------------------------------

2. نظام المكالمات
- مكالمات صوتية مباشرة
- مكالمات فيديو مباشرة
- مكالمات جماعية
- تقنية WebRTC

مميزات المكالمات:
- كتم الصوت / تشغيله
- تشغيل وإيقاف الكاميرا
- مشاركة الشاشة
- جودة تلقائية حسب سرعة الإنترنت
- تغيير الصوت أثناء المكالمة:
  - صوت رجل
  - صوت امرأة
  - صوت طفل
  - أصوات مؤثرات (اختياري)

------------------------------------------------------------

3. نظام الستوري (الحالات)
- نشر حالات مثل واتساب + سناب شات
أنواع المحتوى:
- صور
- فيديوهات قصيرة
- نصوص
- رسائل صوتية
- موسيقى أو مقاطع صوتية
- روابط أو تحديثات

مميزات:
- تختفي بعد 24 ساعة
- عرض من شاهد الحالة
- ردود خاصة
- تنقل بين الحالات بسهولة

------------------------------------------------------------

4. الحسابات والملف الشخصي
- التسجيل بالاسم ورقم الهاتف (بدون تحقق في البداية)
- صورة شخصية
- نبذة تعريفية
- حالة المستخدم (متصل / غير متصل / آخر ظهور)

------------------------------------------------------------

5. الإعدادات
- تغيير الاسم والصورة
- إعدادات الخصوصية:
  - من يمكنه مراسلتي
  - من يشاهد حالاتي
  - إخفاء آخر ظهور
- الإشعارات
- الوضع الليلي / الفاتح
- إدارة التخزين

------------------------------------------------------------

6. نظام الحظر والبلاغ
- حظر المستخدمين
- إلغاء الحظر
- نظام بلاغات:
  - إساءة
  - سبام
  - محتوى غير مناسب
- نظام مراقبة تلقائي
- إيقاف الحسابات عند تكرار المخالفات

------------------------------------------------------------

7. المجموعات والقنوات
- إنشاء مجموعات كبيرة
- صلاحيات:
  - مالك
  - مدير
  - عضو
- قنوات بث (النشر للمدير فقط)
- استطلاعات داخل المجموعات

------------------------------------------------------------

8. نظام الأحداث والمواعيد
- إنشاء حدث أو موعد
- تحديد التاريخ والوقت
- دعوة المستخدمين
- تذكير تلقائي
- تأكيد الحضور أو الرفض

------------------------------------------------------------

9. البحث والاكتشاف
- البحث عن المستخدمين
- البحث عن المجموعات والقنوات
- اقتراح أصدقاء
- اكتشاف مجموعات عامة

------------------------------------------------------------

10. لوحة الإدارة
- إدارة المستخدمين:
  - حظر / إلغاء حظر
- مراقبة الرسائل والبلاغات
- حذف المحتوى المخالف
- إحصائيات النظام:
  - عدد المستخدمين
  - الرسائل اليومية
  - النشاط العام
- تحكم كامل بالنظام

------------------------------------------------------------

11. اللغة (مهم جداً)
- التطبيق يدعم تغيير اللغة بالكامل:
  - العربية
  - الإنجليزية
- واجهة المستخدم تتغير بالكامل حسب اللغة المختارة

------------------------------------------------------------

12. التقنيات المقترحة
- الواجهة الأمامية: React أو Next.js
- الخلفية: Node.js + Express
- قاعدة البيانات: MongoDB أو PostgreSQL
- الاتصال اللحظي: Socket.io
- المكالمات: WebRTC
- التخزين: سحابي (S3 أو مشابه)

------------------------------------------------------------

الخلاصة:
تطبيق تواصل اجتماعي متكامل يحتوي على:
- دردشة فورية
- مكالمات صوت وفيديو
- تغيير الصوت داخل المكالمات
- حالات (ستوري)
- مجموعات وقنوات
- نظام أحداث ومواعيد
- لوحة إدارة كاملة
- دعم لغتين (عربي / إنجليزي)
